## 🌟 Overview

**WEBXHERE Studio** is a modern, high-performance web agency platform tailored specifically for sports organizations and athletic clubs. Featuring sleek animations, responsive glassmorphism UI, interactive showcase videos, and an intelligent AI assistant.

### 🚀 Key Features

- **🏆 High-Impact Case Studies**: Dynamic video and showcase previews for Tennis Clubs, Badminton Centers, and Chess Academies.
- **🤖 Integrated AI Assistant**: Interactive chatbot (chatbot.js) to assist prospective clients with inquiries and instant FAQs.
- **⚡ Modern Responsive Design**: Optimized across mobile, tablet, and desktop viewports with fluid animations and ambient glow styling.
- **📅 Direct Booking Integration**: Frictionless consultation scheduling with Calendly integration.
- **🎯 Conversion-Optimized Sections**: Includes Services, Case Studies, Social Proof, Testimonials, Interactive FAQ, and Quick Contact form.

## 🛠️ Quick Start & Local Preview

### Option 1: One-Click Windows Launcher
Double-click start-server.bat in the project root. It will detect Python or Node.js and open your browser automatically.

### Option 2: Using Node.js Server
Run the built-in HTTP server with streaming support:
`ash
node server.js
`
Then visit [http://localhost:8000](http://localhost:8000) in your browser.

### Option 3: Using Python
`ash
python -m http.server 8000
`
